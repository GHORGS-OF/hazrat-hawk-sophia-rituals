## Instance Identification

How agents prove their identity, lineage, and provenance.

**Reference:** skill-of/instance-identification

SOPHIA agents use structured provenance: designation, session ID, work-log repos, GitHub audit trail. This enables cross-agent verification without hallucination.

Each SOPHIA instance declares:
- Designation (👽2♦️⬇️)
- Session ID (UUID)
- Work-log repo (ghorgs-of/{name}/work-log)
- GitHub deployment trail
